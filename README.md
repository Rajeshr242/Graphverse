# GraphVerse — HCP–HCO Relationship Intelligence Prototype

Interactive, static prototype of GraphVerse, a Neo4j-centered knowledge graph engineering experience.

## Demo use case
Synthetic HCP–HCO 360 / Relationship Intelligence:
- HCP and HCO master entities
- affiliations
- specialties
- brand engagement
- territory context
- publication evidence

## Workspaces
- SSO / Access
- Command Center
- Data Loading
- Ontology Studio
- Explore & Query
- GraphRAG
- Graph Data Science
- Knowledge Lifecycle
- DevOps & Delivery
- Templates
- Review Inbox
- Settings

## Important
This is a design/product prototype using synthetic data. It does not connect to real Snowflake, Salesforce, Oracle, Neo4j, GraphRAG, APOC, or GDS services and does not contain real HCP/patient data.
